## Implementation model
UNTP treats implementation as a first-class part of the ecosystem. The current software implementer register lists organisations and the UNTP capabilities they declare.

Current registered examples include:
- Spherity — VERA
- Trust Provenance
- Tilkal
- Northern Block — Orbit Enterprise, Trust Registry
- FreshChain
- Government of British Columbia — Traction
- ReLOG3P

The current register shows these entries as planned, with observed-credential counts currently at zero in the retrieved page.

## Conformance
Conformance testing is required for implementation registration. UNTP provides testing infrastructure for implementers.

The reference implementation includes:
- UNTP Test Suite
- VC Kit
- Mock Apps
- Identity Resolver

## Why this matters for Soulverse
The ecosystem already contains companies with overlapping SSI/trust capabilities. Therefore, the opportunity should be evaluated as a differentiated implementation proposition rather than simply "joining the list."

## Recommended Soulverse path
1. Map Soulverse capabilities against each UNTP component.
2. Identify missing conformance requirements.
3. Build an adapter/compliance layer where possible rather than rewriting the core platform.
4. Use UNTP test services.
5. Register the implementation once conformance requirements are satisfied.
6. Participate in specification/community work to influence future versions.
