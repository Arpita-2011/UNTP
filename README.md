# UNTP Analysis

Research and implementation analysis of the United Nations Transparency Protocol (UNTP), based on UNECE public documentation.

## Repository structure

- `docs/untp/01-purpose-and-goals.md` — purpose, goals and success measures
- `docs/untp/02-audience-and-market.md` — audiences and market opportunity
- `docs/untp/03-trust-security-and-identity.md` — trust, identity, security and confidentiality
- `docs/untp/04-interoperability-and-standards.md` — standards and interoperability
- `docs/untp/05-implementation-and-adoption.md` — implementation, conformance and ecosystem
- `docs/untp/06-impact-and-use-cases.md` — impact and use cases
- `docs/untp/07-faq-and-governance.md` — governance and participation
- `docs/untp/security-findings.md` — sanitized security review

## Scope

The analysis is based on UNECE's public UNTP documentation and related implementation/tooling pages.

Primary source: https://untp.unece.org/docs/about/

These files are research notes, not official UNECE documentation.
